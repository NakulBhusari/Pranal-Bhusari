# Clinical work case gallery

## Add a patient case

Add one object to `cases.js` with a unique `id`, category, title, image paths, and any available case details. Place the two images in `images/cases/` using the matching names `case-XX-before.jpg` and `case-XX-after.jpg`, then update the object's `before` and `after` paths. Leave unknown fields as empty strings; empty details are not displayed.

Use patient-consented, anonymised images only. Recommended image specs: 4:3 aspect ratio, around 1600px wide, JPG or WebP, ideally under 300KB per image.
